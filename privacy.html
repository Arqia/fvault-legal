FV FVault

Privacy Policy

Effective date: 9 November 2026

FVault is a personal, self-hosted academic dashboard. This policy explains what data FVault accesses, why, and how it is handled.

1. Data FVault accesses

When you connect a Google account, FVault requests read-only access to:

  • Google Classroom courses you are enrolled in;
  • published coursework and its due dates;
  • published course announcements;
  • your own student submission data, as permitted by the requested scope.

FVault currently uses course, coursework, and announcement data to build the dashboard. It does not create, modify, or delete anything in Google Classroom.

2. How data is used

Classroom data is normalized and displayed in a private dashboard so that deadlines and announcements from multiple accounts can be seen in one place. FVault does not use Google user data for advertising, profiling, or resale.

3. Storage and security

OAuth refresh tokens are stored in an encrypted system credential store on a private server. Classroom records are stored in a local SQLite database on the same server. Tokens and personal data are not committed to a public repository, written to logs, or placed in URL query strings.

The dashboard is bound to the server's loopback interface and is accessed through a private network or SSH tunnel. It is not publicly hosted.

4. Sharing

FVault does not sell, rent, or share Google user data with third parties. Data stays on the private server controlled by the operator. No advertising networks or analytics services receive Google user data.

5. Retention and deletion

Data remains on the private server until it is deleted by the operator. You can revoke FVault's access at any time from your Google Account permissions page: https://myaccount.google.com/permissions .

After access is revoked, FVault can no longer fetch new data. Locally stored records can be removed by deleting the FVault database on the private server.

6. Google API Services User Data Policy

FVault's use of information received from Google APIs adheres to the Google API Services User Data Policy , including the Limited Use requirements.

7. Contact

Questions about this policy or FVault's data handling can be sent through the support contact shown on the FVault OAuth consent screen.

8. Changes

If this policy changes, the updated version will be published on this page with a new effective date.
